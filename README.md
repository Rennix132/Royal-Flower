# ROYAL FLOWERS

Frontend-демо карты лояльности ROYAL FLOWERS на Next.js. Форма показывает пример карты в браузере, но не отправляет и не сохраняет введённые данные. Серверной части, API и базы данных нет.

## Запуск

Нужен Node.js 20.9 или новее.

```powershell
npm install
npm run dev
```

## Сборка и публикация

```powershell
npm run build
npm run start
```

`npm run start` запускает production-сборку Next.js.
